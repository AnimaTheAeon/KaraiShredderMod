KARAI + SHREDDER MOD v1.0.4 for TMNT: Splintered Fate (Steam, PC)
==================================================================

NEW IN v1.0.4
- Shredder now wears his purple cape in the game too, not just on the
  select screen. Only the playable Shredder is purple; the boss Shredder
  still has his red cape.

NEW IN v1.0.3
- Karai's tool is now really Kunai and Shredder's is really Smoke Bomb.
  Tool upgrade offers show the right name and icon, and taking an upgrade
  makes the tool stronger. (Before, they said Heckle and Hook.)

NEW IN v1.0.2
- Karai and Shredder now say a line when you swap to them at the lair TV.
- Karai says one of 6 different lines when you pick her on the select screen.

NEW IN v1.0.1
- You can now swap to Karai or Shredder at the TV in the lair between runs.

UPDATING
- Already have an older version? Extract this over the old KaraiShredderMod
  folder, run Install.bat and pick the same option again. It updates in place.

WHAT IT DOES
- Adds Karai and/or Shredder as playable characters, each with their own
  select-screen art, voice, combos, special, tool and Inspirations.
- Karai alone or Shredder alone takes the 9th slot.
  Both: Karai is 9th and Shredder is 10th.

INSTALL
1. Quit the game.
2. Extract this zip into the game folder, so you get:
     ...\Teenage Mutant Ninja Turtles Splintered Fate\KaraiShredderMod\Install.bat
   (Steam > right-click the game > Manage > Browse local files opens that folder.)
3. Double-click Install.bat and pick 1 (Karai), 2 (Shredder) or 3 (Both).
   If Windows says it can't write to the folder, right-click Install.bat >
   Run as administrator.

SWITCH OR UNINSTALL
- Run Install.bat again. You can switch between 1, 2 and 3 at any time.
- 4 = Uninstall: the 4 changed game files go back to 100% original (checked
  file by file) and the mod's backup copies are deleted. Then you can delete
  the KaraiShredderMod folder.
- If anything ever goes wrong: Steam > right-click the game > Properties >
  Installed Files > Verify integrity of game files.

GOOD TO KNOW
- Steam version only, and only the game version this mod was made for.
  If the game updates, the installer refuses to touch the new files (nothing
  breaks) until the mod is updated. A Steam update also removes the mod.
- Single-player only. Don't use it in online co-op.
- Files changed: TMNTSF.exe, PackData\overhead.pak2, PackData\dupes.pak2,
  PackData\default.pak2. Before changing them the installer keeps an original
  copy next to the game (about 840 MB) and backs up your saves to
  %APPDATA%\TMNTSF_save_backup_<date>.
- After uninstalling, a save that last used Karai or Shredder simply starts
  with an original character.
